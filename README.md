# Twist & Turn

**Play the game here:** https://lexicons.itch.io/twist-and-turn

## About the Game
Experience a literal **twist** between two distinct dimensions! 
* **3D Combat World:** Fight the Fun Police in a 3D arena to gather **Light** points.
* **2D Maze World:** Dive into a top-down 2D maze which is dark but is the only **comic** left in the world where you spend your gathered light to reveal hidden map tiles in the dark, acquire weapons, and uncover scattered **comic** panels containing vital hints.

Your ultimate goal? Navigate the twists between these two worlds to free the **comic** character "Fun" and bring color back to the universe!

## Controls
**3D World (Combat):**
* **WASD:** Move
* **J:** Attack
* **Space:** Defend

**2D World (Maze):**
* **WASD:** Move
* **Space:** Spend Light to remove darkness / reveal map tiles

## Setup & Run Instructions
This game is designed to be played directly in the browser. 
1. Navigate to the itch.io link above.
2. Click "Run Game" to load the WebGL build.
3. If the game does not focus, click anywhere inside the game window before using the keyboard controls.
